# Advanced-Threat-Detection-SOAR
Python-based cybersecurity project for automated threat detection, security event correlation, MITRE ATT&amp;CK mapping, and simulated incident response.
## Live Security Operations Center Dashboard

[View Interactive SOC Dashboard](https://david31005.github.io/Advanced-Threat-Detection-SOAR/)

This project demonstrates a simulated Security Operations Center (SOC) environment built with Python, HTML, JavaScript, and GitHub Actions.

### Security Engineering Capabilities

- Automated brute-force and password-spraying detection
- Security event correlation and risk classification
- MITRE ATT&CK technique mapping
- Simulated incident response playbooks
- Interactive browser-based security scanning
- SOC incident investigation and analyst notes
- JSON incident report generation and export
- GitHub Actions CI/CD security testing

### Automated Testing

Five Python unit tests passed in GitHub Actions, covering authentication attack detection and normal activity scenarios.
